# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text is at that link; this page says how it applies here.

## In short

- Be respectful. Disagree about the code, not about the person.
- Assume good faith, and be specific: say what is wrong and what would fix it.
- No harassment, personal attacks, sexualised language or imagery, or publishing someone's
  private information.

This applies to issues, pull requests, discussions and any other space where the project is
represented.

## Reporting

Write to **support@queuethat.com**. Reports are read by the maintainer and kept confidential. Say
what happened, where, and include links or screenshots if you have them.

The maintainer may remove comments, close or lock threads, and block accounts that break these
rules, following the enforcement guidelines of the Contributor Covenant.
