# Spanish (es) guest strings

Machine-translated strings for the guest join, status, kiosk and unsubscribe pages. **Not yet reviewed by a native speaker:** one should check wording and register (neutral Latin American Spanish, informal "tú") before launch.

Staff and admin screens are not translated; they fall back to English. `scripts/check-locales.mjs` fails CI if a key exists in `en` but not here, or the other way round.
