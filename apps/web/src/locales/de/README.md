# German (de) guest strings

Machine-translated strings for the guest join, status, kiosk and unsubscribe pages, in the formal register. **Not yet reviewed by a native speaker:** one should check wording before launch.

Staff and admin screens are not translated into German beyond the files here; they fall back to English. `scripts/check-locales.mjs` fails CI if a key exists in `en` but not here, or the other way round.
